# Branding

Canonical logo sources for gocast (and later govrse).

| File | Use |
|------|-----|
| `gocast_logo.png` | Full wordmark (in-app / marketing later) |
| `gocast_logo_sm.png` | Compact mark → app icons |

Generated platform icons (from `gocast_logo_sm.png`):
- Android: `android/app/src/main/res/mipmap-*/ic_launcher*.png` + adaptive foreground
- Desktop: `desktop/desktopApp/icons/icon.ico` / `icon.png`
